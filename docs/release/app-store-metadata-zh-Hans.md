## Description

把简洁的待办清单放在 Mac 桌面。花瓣清单提供中号和大号小组件，每个小组件显示一张卡片；无需打开 App，就能直接勾选待办。点击卡片可打开编辑器，也可以使用小组件的加号或 Option–Command–N 快速记录。

在轻量编辑器中整理卡片、搜索文字和待办，并从五套主题中选择外观。你可以设置单次或每日提醒；通知声音默认关闭。所有修改先保存在本机，离线时仍可使用。若你主动开启 iCloud 同步，花瓣清单会通过你自己的私人 CloudKit 数据库在 Mac 之间同步卡片。关闭同步后，本地副本仍会保留。

支持导入 Windows 版笔记、导出 JSON 备份或易读的 Markdown，以及从 JSON 备份恢复。无需注册账号；没有广告、订阅、应用内购买、行为分析 SDK 或开发者运营的内容服务器。
