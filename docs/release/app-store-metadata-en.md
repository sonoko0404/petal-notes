## Description

Keep a short, useful checklist on your Mac desktop. Petal's medium and large widgets each show one card, so you can see what matters and check off a to-do without opening the app. Open a card to edit it, or use the widget's plus button or Option–Command–N to capture something quickly.

Organize cards in a lightweight editor, search your notes and to-dos, and choose from five themes. Set optional one-time or daily reminders; notification sound is off by default. Your changes save locally first and remain available offline. If you choose to enable iCloud sync, Petal uses your private CloudKit database to replicate your cards between Macs. You can turn sync off and keep the local copy.

Import notes from the Windows version, export a JSON backup or readable Markdown, and restore from a JSON backup. Petal has no login, ads, subscriptions, in-app purchases, analytics SDK, or developer-operated content server.
