# 帮助

添加小组件前，请先启动花瓣清单。按住 Control 点按 Mac 桌面，选择“编辑小组件”，找到花瓣清单并添加中号或大号小组件。花瓣清单无法自动添加小组件。编辑小组件可选择卡片、五种主题之一、系统字体以及实色或半透明外观。

点按小组件中的待办圆圈即可完成。点按卡片文字打开编辑器，点按加号向该卡片添加内容。Option–Command–N 打开收集箱的快速新增；可在设置中修改或关闭快捷键。Return 保存，Shift–Return 换行，Escape 取消。保存失败时会保留输入以便重试。

已完成待办在当天继续显示，次日从小组件隐藏，但仍保留在 App 中。每日待办在新的本地日期恢复为未完成。在提醒时间前完成每日待办，当天仍可能收到通知；以后的每日提醒会继续。声音默认关闭。

卡片可离线使用。设置中显示 iCloud 同步状态和重试操作。关闭同步保留本地副本。已归档或回收站中的卡片无法通过小组件编辑；可在花瓣清单中恢复，或编辑小组件选择其他卡片。回收站和冲突副本保留 30 天。

编辑器将已完成待办与未完成内容分区显示，并保留手动顺序。撤销完成后，待办回到原来的相对位置。每日连续次数按当地日期计算；撤销移除今天的次数，漏过一天后下次从一开始。使用内容行菜单或 Delete 命令可删除单行。

关闭冲突提示不会删除副本。设置中仍可查看、复制和恢复尚未到期的副本。恢复会创建普通卡片，重复操作不会创建重复卡片。未恢复的冲突副本仅在本机保留 30 天，不包含在 JSON 备份中；请先恢复为普通卡片再导出。

设置提供 Windows 导入、JSON 备份和完整恢复以及 Markdown 导出。导入前会保存备份，Windows 窗口布局会被忽略。完整恢复会替换所有同步设备的数据。删除全部数据需要输入产品名称，并留下一个空收集箱；请先导出备份。清理失败时可在设置中重试。iCloud 可用且同步启用后，云端更改才会完成。

设置中的帮助与隐私页面可离线查看。反馈会打开邮件 App，仅自动填写 App 版本、构建号、macOS 版本和架构。请在发送前检查邮件。支持邮箱将在发布前配置；配置前反馈不可用。
