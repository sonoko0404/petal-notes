# 便利贴 · 使用说明

## 第一次使用

1. 解压整个「便利贴 Windows x64」压缩包。
2. 打开文件夹，双击 **便利贴.exe**。
3. 在便签中直接输入，内容会自动保存到本机。

无需安装，无需登录。请保留程序旁边的文件和文件夹，它们让应用可以在没有安装 .NET 的电脑上运行。

## 随手记录

| 操作 | 方法 |
| --- | --- |
| 新建便签 | 顶部「＋」、托盘菜单，或便签中按 Ctrl+N |
| 移动、缩放 | 拖动顶部空白处；拖动边缘调整大小 |
| 保持置顶 | 顶部实心圆表示已置顶，点击变为空心圆即取消 |
| 收成小条 | 点击顶部折叠箭头，或双击顶部空白处 |
| 隐藏便签 | 点击顶部「×」，或 Ctrl+W；内容保留 |
| 添加待办 | 在「输入待办」处输入内容，按 Enter |
| 完成待办 | 勾选方框，文字会淡化并加删除线 |
| 更换风格 | 右下角「•••」→ 便签风格、字体或字号 |
| 手动保存 | Ctrl+S；通常无需使用，停止输入约半秒自动保存 |
| 删除便签 | 「•••」→ 移入回收站；30 天内可以恢复 |

底部显示「已保存到本机」表示最近修改已落盘。如果显示保存失败，请检查磁盘空间与数据目录权限，保留窗口中的内容并重试。保存失败时正常退出会被取消，以免误以为已保存。

## 找回与管理

双击系统托盘中的便利贴图标，打开便签列表；如果未显示图标，请查看任务栏右侧的隐藏图标区域。也可以再次双击 `便利贴.exe`，应用会唤起已有实例的管理页，不会启动第二套便签。

管理页支持搜索标题、正文和待办，打开隐藏便签，或从回收站恢复。托盘菜单也可全部显示／隐藏、打开设置、查看待处理提醒和退出。

关闭所有便签或管理页后，应用仍在托盘运行。**完全退出请使用托盘或管理页的「退出便利贴」。**

## 提醒与番茄钟

- 点便签底部「提醒」，选择未来日期和 24 小时制时间，例如 `09:30`；也可选择每天重复。
- 到时间后出现不抢输入焦点的小卡片，支持完成、打开便签或 5 分钟后再提醒。默认静音，设置里可开启短提示音。
- 关闭提醒卡片并不完成提醒；托盘的「待处理提醒」可再次打开。
- 点击「专注」开始番茄钟，默认专注 25 分钟、休息 5 分钟，每 4 轮长休息 15 分钟。可在设置中调整时长。
- 全应用只有一个番茄钟，可关联一张便签，支持暂停和重置。每个阶段需要自己点击开始。
- 关闭番茄钟窗口不会停止计时。完全退出应用后不发提醒，重开时汇总错过的提醒；电脑睡眠期间不唤醒电脑，恢复后再检查到期状态。

## 风格与启动

内置奶油手帐、薄荷清新、樱花粉、天空蓝、极简纸张。设置中的风格、字体和字号用于新便签；已有便签可以分别设置。字体取自本机，缺失时回退至微软雅黑。

默认手动启动。需要时在设置里开启「登录 Windows 后自动启动」。开启后请保持程序文件夹的位置不变；移动后可关闭再重新开启该选项，更新启动路径。

## 数据与备份

数据位置：`%LOCALAPPDATA%\BianLiTie`，可在设置中点击「打开数据文件夹」。

- `notes.json`：便签、待办、提醒、计时和外观设置。
- `notes.json.bak`：上一份有效保存的备份。
- `.unreadable-*`：发现损坏时保留的原始文件。

迁移到另一台电脑时，先在两台电脑上退出便利贴，再复制整个数据目录。移动或删除程序文件夹不会自动删除便签数据。应用没有账号或云同步。

置顶用于普通 Windows 窗口，不覆盖系统安全桌面或独占全屏程序。
